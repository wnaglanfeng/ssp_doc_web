# 更新日志

## v0.8+28 (2026-08-12)
### 新功能
- 增加用户体验采集

### 改进
- 删减不必要的库依赖，减少宿主APP的依赖冲突
- 部分页面UI优化

## v2.4.0 (2026-06-02)

### 新功能
- 新增 Uni-app-x UTS 插件支持，可通过 DCloud 插件市场导入
- 插件 ID: `ad-youliang-sdk`
- 支持 uni-app x (Android) 平台
- 使用 `start(options)` 方法启动 SDK，返回 `boolean` 表示启动结果
- 支持自定义主题色、页面标题、顶部栏显隐等配置

### 改进
- 完善 Uni-app-x UTS 插件接入文档，新增配置参数表和常见问题排查指南

## v0.1.0 (2025-10-01)

### 新功能
- Android SDK 初始版本发布
- iOS SDK 初始版本发布
- Uni-app native 插件支持
- 支持 `GYSdk.start()` 启动 SDK
- 配置参数支持: appKey、targetId、oaid、imei、wxAppId、themeColor、title、showAppBar

### 改进
- 提供完整的 SDK 接入文档和代码示例
- 服务端配置文档上线
